# 世界书方案与导入模式边界设计

## 目标

修复世界书方案在导入到组件模式下被覆盖为空的问题，并让已保存方案的载入失败可见、可诊断。

## 设计

- 方案快照只描述提示词编辑模式：世界书来源、提示词勾选、内容覆盖、启用覆盖和关键词覆盖。
- 导入到组件模式只读写独立的导入选择，不建立提示词快照，不参与生成，也不修改已保存方案。
- 切换到提示词编辑模式时不从导入选择恢复提示词选择；方案载入只使用方案快照中的提示词数据。
- 载入世界书方案前检查快照是否包含来源或条目记录。空快照视为损坏，提示用户并保持当前编辑状态不变。
- 数据管理展示每个世界书方案的来源数量、条目记录数量和快照占用，帮助判断数据是否存在。

## 兼容与恢复

保留现有世界书稳定键和懒加载迁移逻辑；不再把临时导入快照作为恢复来源。已经被旧版本覆盖为空的方案无法由插件凭空还原，需从外部备份或历史数据重建。

## 验证

- 方案工具测试覆盖：有效快照可判定为非空，空快照被判定为损坏；载入解析不读取导入选择。
- 现有测试、Node 语法检查和差异检查全部通过。
