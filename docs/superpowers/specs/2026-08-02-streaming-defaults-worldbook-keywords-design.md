# 流式优化、新用户默认值与世界书关键词设计

## 目标

在不改动现有用户设置、不修改酒馆世界书本体的前提下，优化流式生成性能与页面稳定性，为新安装用户提供合理的任务指令默认设置，并允许世界书方案独立覆盖主关键词且按照 SillyTavern 原生规则扫描。

## 分支与发布约束

- 所有改动仅进入 `codex/streaming-defaults-worldbook-keywords` 测试分支。
- 不合并 `main`，不提升版本号，测试后由用户决定是否发布。
- 不处理注入阶段的卡顿。
- 不增加 ST-Prompt-Template/EJS 关键词兼容。
- 不增加次要关键词和 AND/NOT 组合逻辑编辑。

## 新用户默认设置

- 仅全新安装、尚无插件设置的用户默认开启自定义任务指令插入位置。
- 仅全新安装用户默认开启“用任务指令替换 `{{LastUserMessage}}`”。
- 默认插入位置是当前预设的 `Chat History` 标记之后。该默认值使用语义标记，不绑定某一预设条目的动态 key。
- 当前预设缺少 `Chat History` 时，任务指令追加到提示词末尾。
- 已有用户保存的开关、插入位置与任务指令不得迁移或覆盖。
- “恢复默认提示词”使用新的默认文案：

```text
现在停止生成正文，为最新的正文补充下面这些内容。
{{external_components}}
上方为需要补充的内容，现在开始输出思考过程并按规则和格式输出需要补充的内容，禁止额外生成正文。
```

## 流式生成

- 生成开始、进行中、结束或失败时均不强制切换插件分页。
- 流式回调只累计原始文本并以约 80ms 的间隔轻量更新预览框。
- 流式过程中不得调用最终结果标签清理、思维链渲染、结果面板重绘、完整高度重算或设置保存。
- 成功结束后只执行一次最终结果处理和设置保存。
- 用户主动停止时保留已经收到的部分内容，但不得自动注入部分内容。
- 非流式结果、自动注入和错误处理保持现有语义。

## 世界书主关键词编辑

- 世界书条目非编辑状态继续显示“主关键词”。
- 进入现有内容编辑状态后，主关键词行变为一个逗号分隔的输入框，与内容共用现有的保存、取消和恢复原生按钮。
- 保存同时比较内容与关键词：与酒馆原值不同的部分保存为插件覆盖；相同则删除对应覆盖。
- 取消不写入任何覆盖。
- 恢复原生同时移除内容覆盖与主关键词覆盖。
- 关键词覆盖属于世界书方案快照，参与保存、加载、覆盖、删除和“只看已修改”。
- 插件覆盖不回写酒馆世界书。

## SillyTavern 原生关键词规则

- 单输入框用逗号分隔关键词。
- 合法的 `/pattern/flags` 内部逗号不作为分隔符。
- 正则允许 `gimsuy` 标志；未转义的内部 `/` 使其不被识别为正则。
- 无效正则样式字符串按普通文本匹配，不阻止保存。
- 每个关键词匹配前先执行 SillyTavern 标准宏替换。
- 合法正则直接匹配完整扫描文本，并避免全局或粘滞正则的 `lastIndex` 污染后续扫描。
- 普通关键词遵循条目的 `caseSensitive` 与 `matchWholeWords` 元数据。
- 多个主关键词为任意一个命中即触发。
- 扫描文本继续使用聊天记录清理后的最近可见消息，并包含正文内已注入的状态栏。

## 验证

- 为新旧用户默认设置、语义化 Chat History 插入、流式节流与停止保留部分结果、关键词解析/匹配、关键词覆盖与方案快照增加自动化测试。
- 运行 `npm.cmd test` 与 `git diff --check`。
