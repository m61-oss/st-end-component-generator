# 生成页与世界书编辑细节设计

## 目标

- 世界书条目在任一模式下只显示一处主关键词；编辑模式使用可编辑框，导入模式使用只读文字。
- 每次新生成开始时立刻隐藏并清空上次生成的思维链，流式过程中不解析标签，生成结束或停止后才统一解析并显示本次思维链。
- 生成预览框随流式内容增高，达到基于视口的高度上限后允许内部滚动；用户停留在底部时自动跟随，主动向上滚动后不抢回位置。

## 性能约束

流式内容继续经过现有的 80ms 控制器合并。高度测量只在合并后的预览更新中执行，不运行标签清理、结果面板重绘或设置保存。最终结果仍只处理一次。

## 边界

- 不改变 API 请求、注入和自动生成规则。
- 不增加用户设置项。
- 不修改版本号或合并 `main`。
