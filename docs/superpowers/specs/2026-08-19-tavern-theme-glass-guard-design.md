# 跟随酒馆主题玻璃兜底设计

## 目标

让“跟随酒馆”继续采用酒馆主题颜色，同时避免酒馆背景变量为透明或半透明时，织幕主面板、弹窗与悬浮球失去自身层次和可读性；主题入口图标需要同时表达“主题”与“同步跟随”。

## 视觉方案

- 仅在 `tavern` 主题模式启用织幕玻璃保护层，夜间与日间模式保持现状。
- 主面板外壳及插件自有弹窗使用酒馆主题背景变量，并额外获得统一的最低玻璃底与 `16px` 背景模糊。
- 玻璃底使用酒馆正文色生成低透明度中性色层，不硬编码为纯黑或纯白；酒馆颜色仍是主要颜色。
- 卡片、输入框等内部层级继续使用现有主题令牌，不重复添加背景模糊，避免发灰和性能浪费。
- 悬浮球继续跟随酒馆颜色，但其表面颜色混入最低限度的织幕保护层，避免完全透明。

## 图标方案

- 夜间和日间图标保持月亮与太阳。
- “跟随酒馆”改为调色盘主图标，并叠加小型同步箭头角标。
- 按钮标题与无障碍文本继续明确显示“主题：跟随酒馆”。

## 实现边界

- 不新增 MutationObserver、定时器或高频重绘。
- 酒馆主题变化仍依靠 CSS 自定义属性继承即时生效。
- 玻璃保护通过跟随主题专属 CSS 令牌和外壳类实现。
- 不修改主题切换顺序及现有用户设置迁移逻辑。

## 验证

- 单元测试验证跟随主题使用组合图标描述。
- 静态样式测试验证玻璃保护令牌、最低模糊度及悬浮球保护层存在。
- 运行完整测试、JavaScript 语法检查和 Git 空白检查。
