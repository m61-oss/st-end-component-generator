# 楼层面板设计

## 目标与范围

楼层面板是挂在当前聊天最新 assistant 楼层底部的织幕快捷入口，用于查看生成状态、浏览流式结果、编辑待注入内容以及执行生成、停止、注入和撤回操作。

- 整个聊天只存在一个楼层面板实例。
- 面板只属于最新 assistant 楼层，不在历史楼层保留副本或隐藏节点。
- 面板不替代主面板的额外指令、API、注入方式等设置。
- 面板开关位于“界面与快捷入口”，默认关闭，且不影响其他入口。

## 挂载与生命周期

面板作为消息正文之后的界面节点挂入最新 assistant 楼层，但不写入楼层正文数据。

- 新 assistant 楼层出现时，将同一个面板实例移动到新楼层并恢复折叠空闲状态。
- 切换聊天时，移动到新聊天的最新 assistant 楼层。
- 当前聊天没有 assistant 楼层时完全隐藏。
- 滑动回复、删除楼层或重新生成正文后重新确认目标，不保留无效关联。
- 刷新页面后不恢复展开状态、预览内容或运行状态。
- 未注入的旧结果继续保留在主面板“最近生成记录”中，不跟随面板移动到新楼层。

## 折叠栏

面板默认折叠，生成、完成、注入和失败均不得自动展开。用户手动展开后，状态变化不改变展开状态；切换聊天或出现新 assistant 楼层时重新折叠。

折叠栏包含织幕标识、小型生成操作、展开箭头以及必要时出现的工作状态。空闲时不显示状态文字。

仅允许以下四种状态文案：

- `生成中`
- `生成完成 · 待注入`
- `已注入`
- `生成失败`

小型生成操作在生成期间变为停止操作；其余状态下用于生成或重新生成。

## 展开内容

### Thinking

- 使用与主面板相同的解析结果，默认折叠。
- 流式生成时同步更新。
- 不允许编辑。
- 没有 thinking 时不渲染空区块。

### 生成内容

- 普通追加或替换模式显示可编辑文本区域。
- 锚点模式显示与主面板一致的锚点卡片。
- 锚点文本、插入内容以及单项是否注入均可编辑。
- 楼层面板与主面板共享同一份当前生成状态；任一侧编辑后，同步更新另一侧、实际待注入内容以及对应的最近生成记录。
- 流式生成期间内容只读，生成结束后开放编辑。
- 注入完成后内容锁定；撤回注入后恢复可编辑，避免界面内容与楼层中已注入版本不一致。

### 快捷操作

- 空闲：`生成组件`
- 生成中：`停止生成`
- 生成完成：`重新生成`、`注入回复`
- 已注入：`重新生成`、`撤回注入`
- 生成失败：错误摘要、`重试`

展开区域不提供“打开织幕”，不复制额外指令、API 或注入设置。

## 流式表现与性能

- 折叠时仅更新内存中的流式缓存与简短状态，不持续重绘隐藏预览。
- 用户在生成过程中展开时，先一次性渲染当前完整缓存，再按现有节流频率继续更新。
- Thinking 与实际输出分别解析，JSON 外层封装不进入可见区域。
- 非流式生成只显示生成状态，请求结束后一次性渲染结果。
- 展开内容拥有独立滚动区域，不因流式更新强制拖动聊天页面。

## 目标校验与异常处理

生成开始时保存临时目标信息：

- 当前聊天标识
- assistant 楼层序号
- 目标正文指纹

注入前必须重新核对。若目标正文已被滑动、重新生成、编辑或替换，不得注入当前结果；面板进入 `生成失败`，展开后说明“目标楼层已变化，请重新生成”。

若生成过程中出现新的 assistant 楼层，应停止或作废旧请求的界面结果，并在新楼层恢复折叠空闲状态。无法真正取消的网络响应即使随后返回，也不得覆盖新目标的状态。

导入模式拦截、API 错误、解析失败与注入失败继续使用现有错误规则；楼层面板只展示错误摘要和重试操作。

## 设置与持久化

- 在“界面与快捷入口”新增“楼层面板”开关。
- 默认关闭。
- 仅持久化该开关。
- 不持久化展开状态、临时预览、thinking、错误或目标信息。

## 验证范围

- 单实例随最新 assistant 楼层移动，旧楼层不残留面板。
- 无 assistant 楼层时隐藏。
- 所有状态变化均不自动展开。
- 折叠时不执行预览区高频 DOM 更新，展开中保持节流流式显示。
- 普通输出和锚点计划的双向编辑同步正确。
- 注入后的锁定及撤回后的解锁正确。
- 目标正文变化时拒绝注入，迟到的旧请求不能污染新楼层。
- 设置默认关闭，且不影响现有悬浮球与其他入口。
