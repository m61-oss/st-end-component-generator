# 输出协议默认身份调整设计

## 目标

- 普通模式与锚点模式的默认消息身份统一为 `assistant`。
- 当前测试环境中已经保存的旧身份一次性迁移为 `assistant`。
- 一次性迁移完成后，继续保存并尊重用户后来手动选择的身份。
- “恢复当前内置协议”只恢复当前模式的协议文本，不修改消息身份。

## 实现

- 将 `DEFAULT_SETTINGS` 中两种协议的角色默认值改为 `assistant`。
- 增加一次性迁移标记；标记不存在时，把两种协议角色设为 `assistant` 并保存标记。
- 删除重置事件中修改角色的语句，保留文本恢复、界面刷新、保存与状态提示。

## 验证

- 源码测试确认两种默认角色都是 `assistant`。
- 源码测试确认一次性迁移同时更新两种角色与迁移标记。
- 源码测试确认重置处理只修改文本，不修改角色。
- 运行全部已跟踪测试、语法检查和差异空白检查。
