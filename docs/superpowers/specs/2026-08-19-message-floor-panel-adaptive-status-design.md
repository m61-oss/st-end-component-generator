# 楼层面板自适应与状态动画设计

## 目标

优化最新 assistant 楼层下方的织幕面板，使其在短内容时保持紧凑、始终不超过正文气泡宽度，并用文字、颜文字与符号共同组成可理解的状态动画。顶部操作按钮同步缩小，但仍保留足够的触控热区。

## 自适应内容高度

- 普通输出框不再设置固定高度或 220px 的最小高度。
- 根据实际内容行数在约 3 至 10 行之间自动增长。
- 超过最大可见高度后，仅输出框内部滚动。
- 流式输出时同步更新高度；用户停留在底部时继续跟随最新内容，主动上翻后保持当前位置。
- 锚点卡片不再无条件采用统一高卡片：内容较少时自然收紧，内容较多时达到上限后在字段内部滚动。

## 气泡宽度约束

- 楼层面板采用 `box-sizing: border-box`，边框和内边距必须包含在最终宽度内。
- 面板宽度以最新 assistant 正文元素的可见宽度为上限，同时不得超过承载它的消息内容容器。
- 宽度同步后仍保留 CSS 的 `width: 100%`、`max-width: 100%` 与 `min-width: 0` 防线。
- 窗口、主题、字体或消息气泡尺寸变化时重新同步，不允许产生横向滚动或越出气泡。

## 状态小剧场

删除独立状态文字和现有三条抽象线。中间区域只保留一个状态舞台，文字、颜文字和符号共同表达状态并参与动画。

### 空闲

显示：`｡･ﾟ 织幕在打盹 (˘ω˘) ﾟ･｡`

- 两侧星屑缓慢漂动。
- 颜文字进行幅度很小的呼吸。

### 生成中

显示：`✦･ﾟ ⋈ 正在编织 (ง •̀ω•́)ง ･ﾟ✧`

- `⋈`沿状态舞台横向穿梭。
- 穿过的位置依次点亮星屑。
- 颜文字轻微上下动作，强化正在工作的感觉。

### 生成完成待注入

显示：`｡･:*:･ﾟ✦ 织好啦 (｡•̀ᴗ-)✧ ﾟ･:*:･｡`

- 状态切换时星屑向外舒展一次。
- 完成动画后保持安静，避免循环闪烁。

### 已注入

显示：`◇ ･ﾟ 内容嵌好啦 (๑˃ᴗ˂)ﻭ ﾟ･ ◈`

- 空心菱形横向进入右侧符号。
- 右侧由 `◇`变为 `◈`，表达内容已经嵌入。
- 不使用对勾图标。

### 生成失败

显示：`⌁ ･ﾟ 线团打结了 (｡•́︿•̀｡) ﾟ･ ⌁`

- 两侧线结向中间卷起一次，再略微松开。
- 不使用警告三角形，不持续抖动。

### 窄屏与减少动态效果

- 窄屏优先缩短两侧装饰轨迹，不挤压右侧操作按钮。
- 状态舞台保持单行，必要时隐藏最外层装饰，但保留状态文字、颜文字与核心符号。
- `prefers-reduced-motion: reduce` 下禁用位移和循环动画，所有状态仍能仅凭文字与符号识别。

## 顶部操作按钮

- 可见图标尺寸与按钮外观缩小，使其不抢占状态舞台。
- 触控热区仍至少保持 28px，不因视觉缩小而变得难点。
- 操作按钮继续阻止折叠栏的展开事件，点击按钮不得误触开合。

## 验证

- 短文本、长文本、空内容和流式内容分别验证高度。
- 桌面与手机宽度下验证面板不越出正文气泡。
- 验证五种状态的文字、颜文字、符号和动画映射。
- 验证减少动态效果模式。
- 验证缩小后的按钮仍可点击，且不会触发折叠栏开合。
- 运行楼层面板、主题、品牌图标及完整仓库测试。
