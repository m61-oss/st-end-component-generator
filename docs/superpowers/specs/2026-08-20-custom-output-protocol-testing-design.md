# 自定义输出协议测试栏设计

## 目标

在任务指令页面提供一个仅用于当前测试阶段的自定义输出协议区域，让用户分别调整普通模式与锚点插入模式的协议内容，并为每种协议选择 `system`、`user` 或 `assistant` 消息角色。

## 界面

- 区域位于任务指令页面。
- 使用互斥切换在“普通模式”和“锚点模式”之间切换。
- 当前模式显示一份协议文本框和一项消息角色选择。
- 两种模式默认载入现有内置协议，默认角色均为 `system`。
- 提供“恢复当前内置协议”操作，只重置当前选中的模式及其角色。

## 数据与行为

- 普通模式和锚点模式分别保存协议文本与角色。
- 配置只进入插件普通设置，不加入任务指令方案，也不随任务方案保存或载入。
- 生成时根据当前输出模式选择对应协议和角色，并把协议消息保持在现有的提示词末尾位置。
- 自定义协议完全替换当前模式的内置协议，不与内置协议叠加。
- 内置协议继续作为默认值和恢复来源。

## 兼容边界

- 生成结果解析器保持不变。
- 普通模式仍要求生成结果满足当前 `thinking` / `output` 结构。
- 锚点模式仍要求 `output` 为插入计划数组。
- 用户若在测试中改变必要字段或数据结构，允许解析失败；测试栏不自动改写用户输入。
- 本次不处理任务方案绑定、正式版迁移、协议版本管理或更多插入位置。

## 验证

- 两种模式的文本与角色可以独立编辑并在刷新后恢复。
- 切换模式不会覆盖另一种模式的草稿。
- 三种角色均能原样进入最终 API 消息。
- 协议消息仍位于消息列表末尾。
- 恢复操作仅恢复当前模式的内置协议和 `system` 角色。
- 未修改设置时，生成结果与当前版本完全一致。
