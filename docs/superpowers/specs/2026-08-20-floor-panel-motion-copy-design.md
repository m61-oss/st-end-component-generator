# 楼层面板动效、文案与锚点布局设计

## 范围

本次只优化现有楼层面板及插件对外文案，不改变生成、解析和注入逻辑。

## 锚点卡片

`before/after` 卡片继续保持统一固定高度。锚点输入框从平均占据半张卡片改为内容自适应：默认一行，随换行或折行增长，最多三行，超过后仅在锚点框内部滚动。卡片剩余高度全部交给插入内容输入框。`start/end` 卡片保持现状。

## 状态舞台

- 已注入状态文字改为“内容注入好啦”。
- 状态文字本身参与动画，而不是只让颜文字和装饰符号运动。
- 不再以左右伸缩作为主要运动。不同状态分别使用轻微上下漂浮、呼吸、落定、明暗波动和小幅不规则抖动。
- 舞台增加两个小型主题色微光点，并让文字阴影随当前 `--floor-accent` 与 `--floor-text` 混合色变化。
- 发光保持低透明度和小范围，不改变文字可读性，不形成突兀霓虹效果。
- `prefers-reduced-motion: reduce` 下关闭全部文字、符号和伪元素动画与发光。

## 通用文案

插件已经支持追加、替换和任意锚点插入，因此面向用户的“文尾”统一改成更通用的“组件”“注入回复”或在位置语义中使用“文末”。扩展显示名改为“织幕·组件生成器”。英文包名、仓库路径和历史设计文档不变。

## 验证

- 一句话锚点只占一行，插入内容获得更多空间。
- 五种状态的文字都存在明确动画，且不依赖横向伸缩。
- 微光颜色来自面板主题变量并支持减少动态效果。
- 运行时代码、清单和 README 不再出现旧的“文尾”产品措辞。
