# 重 Roll、最近生成记录与调试信息页设计

## 目标

保留现有生成预览和自动注入流程，只调整两个“撤回后注入”模式的撤回时机，并增加最近生成记录、面板版本号和统一的调试信息页。

## 撤回与注入

- 普通追加和普通覆盖保持现状。
- 选择“撤回本楼上次注入后追加”或“撤回本楼上次注入后覆盖”时，在新一轮生成开始前先执行已有的本楼注入撤回。
- 生成前撤回不弹确认框，也不会在生成失败、停止或报错后自动反向恢复。
- 撤回成功后清除本次撤回快照。随后如果发生新注入，仍按原机制在注入前保存当时的完整正文，供下一次撤回使用。
- 如果生成开始时没有有效撤回快照，则不修改正文，继续正常生成。
- 手动载入历史结果并注入时，仍按当前注入模式执行；若选择撤回后注入且存在有效快照，则先撤回当前注入，再注入所选结果。
- 删除为虚拟提示词引入的 `promptBaseText`、`promptBaseSwipeText` 双重快照逻辑，恢复单一“本次注入前正文”快照。
- 撤回与重新注入继续同步当前 Swipe，并沿用现有 MVU 重处理规则。

## 最近生成记录

- 保留现有预览框，预览框始终显示本次最新生成内容。
- 每次完整生成成功后，将与预览框一致的最终结果写入浏览器本地存储。
- 记录按生成时间倒序排列，最多保留三条；每次成功生成都新增一条记录。
- 生成失败、用户停止后留下的部分输出不进入记录。
- 每条记录保存生成时间和生成内容。
- 点击记录的“载入”只把该内容复制进现有预览框，并同步现有 `lastGenerated` 状态。
- 载入、查看和编辑预览框不会修改、重排或新增最近记录。
- 最近记录自身不执行自动注入。用户载入后通过现有“注入回复文尾”按钮手动注入。
- 清理浏览器站点数据后记录允许丢失；记录不写入酒馆 `settings`，也不跨设备同步。

## 页面调整

- 在面板顶部“外置文尾组件生成器”标题旁显示当前插件版本，例如 `v0.1.4`。版本直接复用插件现有版本常量，不维护第二份版本值。
- 生成页保留生成设置、当前预览和操作按钮，并增加“最近生成记录”卡片。
- 将“本次生成日志”从生成页移走。
- 将“提示词查看器”Tab 改名为“调试信息”。
- 调试信息页上方显示“本次生成日志”，下方保留完整的提示词查看器。
- 本次生成日志仍在每次生成开始时清空；即使用户没有打开调试信息页，也继续在后台记录并在切换页面后显示。

## 异常处理

- 生成前撤回完成后，即使 API 失败或用户停止，也保持撤回后的正文。
- 最近生成记录用于让用户手动载入并重新注入之前的结果，不自动恢复正文。
- 最近记录读取失败或浏览器不允许本地存储时，不影响正常生成、预览和注入。
- 自动注入失败时，本次成功生成结果仍保留在预览框和最近生成记录中。

## 验证

- 连续使用撤回后注入模式时，每轮生成前都会恢复本次注入前正文，不再依赖长期纯正文基线。
- 普通追加、普通覆盖、手动注入、自动注入、Swipe 和 MVU 相关测试保持通过。
- 成功生成写入最近三条，失败或停止不写入；载入历史不改变历史顺序和数量。
- 面板显示版本号，生成日志只出现在“调试信息”页，提示词查看器功能保持不变。
