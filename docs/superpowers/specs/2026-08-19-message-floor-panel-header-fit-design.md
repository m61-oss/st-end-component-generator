# 楼层面板顶栏适配修正设计

## 目标

让楼层面板严格贴合最新 assistant 正文的可见边界，并让折叠顶栏在宽、窄气泡中都保持清晰、饱满和可操作。

## 边界同步

- 面板继续作为 `.mes_text` 的相邻元素存在，不进入聊天正文。
- 同步时同时读取目标正文的宽度与其相对父容器内容区的水平偏移。
- 面板以内联重要样式固定 `box-sizing: border-box`、宽度、最大宽度和左侧偏移，避免酒馆主题或自定义 CSS 把边框重新算到宽度之外。
- ResizeObserver 仍监听正文尺寸变化，并重新同步完整横向边界。

## 顶栏结构

顶栏只保留三部分：织幕图标、自适应状态舞台、右侧操作键。删除专门的展开键；点击顶栏中除操作键外的区域切换展开状态，键盘 Enter/Space 行为保持不变。

右侧操作区固定保留宽度，不允许状态动画把它挤出可视区域。操作键仍阻止点击冒泡，因此不会误触发展开或收起。

## 自适应状态舞台

- 中央核心固定显示状态文字与颜文字，不通过缩小字号适配。
- 核心左右各有一条弹性符号轨道，使用当前状态对应的重复符号填充可用宽度。
- 宽气泡显示更多符号；窄气泡优先裁切轨道外侧，核心与操作键保持可见。
- 生成状态的 `⋈` 沿符号轨道移动；其他状态继续使用与含义相符的轻量动画。
- 顶栏减少上下留白，状态字号在移动端不再降到 `9.5px`。

## 验证

- 静态 UI 测试确认同步函数写入偏移、强制 border-box 和精确宽度。
- 静态 UI 测试确认展开键从结构中移除，而整栏键盘与点击切换仍存在。
- 静态 UI 测试确认符号轨道可伸缩、核心不可收缩、操作区固定可见。
- 运行楼层面板定向测试、完整仓库回归、语法检查与界面静态检测。
