# 楼层锚点卡片高度设计

## 目标

楼层面板生成多个锚点时，每张卡片保持稳定、可编辑的高度，锚点列表按卡片数量自然撑高，不再产生列表内部滚动。用户可随时通过列表末尾的折叠栏收起整个面板。

## 布局规则

- `start`、`end` 卡片使用紧凑固定高度，只显示“插入内容”。
- `before`、`after` 卡片使用较高固定高度，显示“锚点”和“插入内容”。
- 卡片列表取消 `max-height` 与 `overflow: auto`，由页面承担纵向滚动。
- 卡片内部文本框占据固定区域；长内容只在对应文本框内部滚动，不继续撑高卡片。
- 被取消注入的卡片保持原高度，仅降低视觉强度，避免布局跳动。
- 底部折叠栏始终位于最后一张卡片之后。

## 匹配状态

每张卡片标题栏显示其定位状态，例如“精准匹配”“宽松匹配”“模糊匹配”“未匹配”“开头”“末尾”。状态标签使用与楼层面板一致的主题文字色和较低透明度，不使用高饱和色抢占视觉层级。

## 响应式与边界

- 手机与桌面使用相同的两档高度逻辑，只允许间距细调。
- 卡片数量不设列表内部滚动上限；卡片越多，楼层面板自然越高。
- 文本框仍允许用户编辑，并保留自身的纵向滚动能力。

## 验证

- CSS 结构测试覆盖两档固定高度、自然增长列表、文本框内部滚动和低透明度状态标签。
- 既有楼层面板、锚点编辑、单项取消注入与自动尺寸测试继续通过。
