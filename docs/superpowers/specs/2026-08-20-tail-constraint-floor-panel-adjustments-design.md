# 尾部格式约束与楼层面板调整设计

## 目标

把当前任务页中的自定义输出协议测试区改为位于页面最下方的折叠栏“尾部格式约束”，并完善楼层面板的默认启用、跨插件排序和主题字体继承行为。

## 尾部格式约束界面

- 不改动任务指令卡片现有内容和布局。
- 在任务指令页面所有现有内容之后追加一个独立 `details` 折叠栏。
- 折叠栏标题仅显示“尾部格式约束”，展开区域不重复标题。
- 展开区域顶部显示说明：

  > 按所选身份原样作为提示词最后一条消息发送；留空则不插入。普通与锚点模式分别保存，不随任务方案保存。

- 说明下方依次提供普通/锚点模式切换、`system` / `user` / `assistant` 身份选择、协议文本框和“恢复当前内置协议”按钮。
- 普通与锚点模式继续独立保存文本和身份，但不进入任务方案快照。
- 文本框内容不做裁剪、补全或自动改写。文本为空字符串时，不创建尾部格式约束消息；其他提示词消息的位置和顺序保持原状。

## 普通模式默认协议

保留当前普通模式内置协议全文，只在最末尾追加：

```text
<think>
我已详细阅读格式输出规则，我将直接输出json，并在json内部输出推演步骤及内容。
</think>
```

## 锚点模式默认协议

锚点模式内置协议整体替换为：

```text
【固定输出协议｜锚点插入模式｜最高优先级】

本协议只规定完整回复的外层 JSON 封装与锚点插入计划，不改变任务要求的内容、步骤或内部格式。"output" 只承载本次任务明确要求的实际交付；忽略续写正文要求，不得在 JSON 外生成正文。

【唯一目标范围】

唯一允许匹配和插入的目标，是<latest_assistant_target>后的正文内容，更早的正文只能作为背景，不得从中复制文字、生成 "anchor" 或规划插入。 "anchor" 或 "content"。

完整回复必须且只能是：
{
"thinking": "全部思考、推演与插入规划，使用中文",
"output": [
{
"position": "start | end | before | after",
"anchor": "仅 before/after 时填写",
"content": "本次新增的实际内容"
}
]
}

规则：

1. 顶层仅允许 "thinking"、"output" 两个字段并保持此顺序；"thinking" 为字符串，"output" 为数组。
2. "output" 可为空或包含任意数量插入项；根据任务实际需要决定是否插入、插入几项及位置，不得机械凑数或固定同时生成 "before" 和 "after"。
3. "start" 表示插入目标完整原文最前方；"end" 表示插入目标完整原文最后方，均不填写 "anchor"。目标范围包含正文后的闭合标签、状态块、HTML/XML、注释及其他尾部字符，因此 "end" 不得改用“最后一句正文”作锚点。
4. "before/after" 分别插入 "anchor" 前/后。"anchor" 必须从目标范围内逐字复制一段连续原文，且只出现一次。
5. 若 "anchor" 重复，应扩大连续复制范围直到唯一。
6. "content" 只包含本次新增的实际内容及其既定格式，不得重复写入 "anchor"、说明或思考。
7. 所有思考只放入 "thinking"，所有实际交付只放入对应项的 "content"。
8. JSON 外不得输出任何字符、解释、标题或代码围栏；严格按 JSON 规则转义双引号、反斜杠和换行。
9. 完整回复必须以 "{" 开始、以 "}" 结束。
<think>
我已详细阅读格式输出规则，我将直接输出json，并在json内部输出推演步骤及内容。
</think>
```

## 楼层面板默认启用

- 新安装默认启用最新楼层面板。
- 更新用户首次加载本次改动时也自动启用一次，并写入一次性初始化标记。
- 初始化完成后，用户手动关闭的选择会持续保留，后续加载不再强制开启。
- 运行设置中的“最新楼层面板”开关只保留名称和复选框，删除旁边说明。

## 楼层面板跨插件排序

- 楼层面板不再追求成为楼层最后一个元素，而是保持为正文元素后的第一个兄弟元素。
- 每次定位或渲染楼层面板时检查 DOM 位置；若被其他插件挤到更下方，则重新移动到正文之后。
- 这样其他同样挂在正文后的插件面板会自然排在织幕下面，不依赖对方插件的类名或加载顺序。
- 移动现有节点，不重新创建面板，不丢失生成状态或编辑内容。

## 楼层面板主题字体

- 删除楼层面板当前硬编码的系统字体栈。
- 楼层面板根节点、按钮、输入框和文本框统一继承所在酒馆楼层的实际字体。
- 颜色、透明度和织幕主题表面样式保持现状；本次只改变字体来源。

## 验证

- 任务指令原文与任务方案快照保持不变。
- 折叠栏位于任务页最下方，标题不在展开区域重复。
- 普通与锚点协议及身份独立保存，空协议不会产生尾部消息。
- 两份内置默认协议与本规格文本一致，重置只影响当前模式。
- 更新初始化只自动启用楼层面板一次，之后尊重用户关闭选择。
- 楼层面板始终恢复到正文后的第一个位置，其他插件面板可以留在其后。
- 楼层面板所有可见文字与控件继承酒馆主题字体。
