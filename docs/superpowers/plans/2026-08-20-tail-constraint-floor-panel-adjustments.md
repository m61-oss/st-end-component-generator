# 尾部格式约束与楼层面板调整实施计划

**目标：** 将自定义输出格式改为任务页底部的“尾部格式约束”折叠栏；支持留空时不插入尾部消息；更新两套默认协议；让楼层面板一次性默认开启、稳定位于正文后的第一个位置并继承酒馆主题字体。

## 任务一：尾部消息与内置协议

- 先在 `generation/output-protocol.test.mjs`、`generation/prompt-builder.test.mjs`、`generation/anchor-output-protocol.test.mjs` 添加失败测试。
- 普通默认协议末尾追加用户指定的 `<think>...</think>`。
- 锚点默认协议完整替换为用户指定文本。
- 显式留空时 `buildOutputProtocolMessage` 返回 `null`，提示词构建器不追加空消息，也不改变其他消息顺序。
- 运行聚焦测试并提交。

## 任务二：任务页底部折叠栏

- 先在 `ui/custom-output-protocol.test.mjs` 添加失败测试。
- 保持现有任务指令内容不变，把原编辑器移动为任务页最后一个独立 `details`。
- 折叠栏标题仅为“尾部格式约束”，展开后不重复标题。
- 展开后的说明为：`按所选身份原样作为提示词最后一条消息发送；留空则不插入。普通与锚点模式分别保存，不随任务方案保存。`
- 保留现有模式、身份、文本框、重置按钮及事件逻辑。
- 运行聚焦测试并提交。

## 任务三：楼层面板默认值、顺序与字体

- 先在 `ui/message-floor-panel-ui.test.mjs` 添加失败测试。
- 增加一次性迁移标记：未迁移用户自动开启楼层面板并保存标记；此后尊重用户手动关闭。
- 每次渲染时把已有楼层面板移动为正文后的第一个相邻元素，不重建节点。
- 删除运行设置中楼层面板开关旁的说明文字。
- 楼层面板及其按钮、输入框、文本框和下拉框继承酒馆主题字体。
- 运行聚焦测试和全部已跟踪测试并提交。

## 任务四：验证与发布

- 运行 `node --check index.js`。
- 运行所有已跟踪的 `.test.mjs`（排除临时数据库目录）。
- 运行 `git diff --check`。
- 推送 `codex/message-floor-panel` 到 GitHub，供手机拉取测试。
