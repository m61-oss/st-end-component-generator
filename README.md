# 织幕·组件生成器

为 SillyTavern 提供独立 API 的组件生成与注入功能。它可以把预设、世界书和组件库中的内容组合成提示词，生成后再注入最新回复。

## 功能

- 使用 OpenAI 兼容 API 生成组件，支持流式输出。
- 支持全局、预设和角色组件库，以及预设、世界书来源选择。
- 支持聊天历史和生成内容的成对标签清理。
- 支持提示词模板兼容模式、提示词日志和 Quick Reply 快捷入口。
- 可选规范化 `<StatusPlaceHolderImpl/>`：保留回复正文内容，并确保文末只有一个该标记。

## 安装

在 SillyTavern 的扩展管理中安装第三方扩展，填入：

`https://github.com/m61-oss/st-end-component-generator`

安装后打开“织幕·组件生成器”，在“运行设置”填写 API 地址、模型和 API Key。

## 使用

1. 在“任务指令”和“组件库”配置要发送给模型的内容。
2. 点击“生成组件”，在生成区检查结果。
3. 选择注入方式后点击“注入回复”。

“正文已有同名成对标签时替换”会以生成结果中的成对标签名匹配最新回复的同名成对标签；“始终追加到最新回复末尾”则直接追加。

## 说明

- API Key 保存于本地 SillyTavern 扩展设置，不会写入仓库。
- `StatusPlaceHolderImpl` 的规范化扫描原始楼层文本，不依赖聊天记录标签清理结果。
